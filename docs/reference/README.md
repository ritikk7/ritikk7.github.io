# Reference Material

This directory preserves documentation inherited from the Indigo theme. It is
kept for implementation context and is excluded from the generated website.

Renderable examples live under `_drafts/reference/`. They are excluded from
normal production builds and can be previewed locally with:

```powershell
bundle exec jekyll serve --drafts --host 127.0.0.1 --port 4000
```

Reference files may describe legacy APIs, embeds, or theme behavior. Confirm
that an example is still appropriate before using it in production content.
